# Coaching protocol

The training programme the app exists to serve. The software is equipment; this
is what to do with it. Written by the owner as a brief, kept here so it survives
outside any one conversation.

## Framing

These are visual search drills and, when the gaze stays central, practice at
using the edges of vision. They are not an IQ exercise and they do not enlarge
anyone's visual field. Say so plainly rather than implying otherwise — the app's
own copy follows the same rule.

## Phone form

- 30–40 cm from the face, portrait.
- In Eyes mode: fixate the centre of the grid, find the next number, then press
  the confirm button. No finger hovering over cells.
- Have the next number in mind before confirming the current one.
- Finish every grid. No rage-restarts.

## The owner's custom table

6 columns × 4 rows, numeric, shuffle off, **Eyes on**, colour off — 24 cells,
1–24. Treat it as a wide 5×5. The app labels it `4 × 6`, since grids are
displayed rows × cols.

## A session, 5–8 minutes

1. Warm-up: one grid, untimed — the 6×4 custom or a standard 5×5.
2. Three timed rounds on the agreed table.
3. Optional: one harder round — shuffle on, or Gorbov, or 5×5 hardcore.
4. Stop.

## Progression

One variable at a time, and only once the current setting is comfortable.

1. 6×4, Eyes on, shuffle off — home base.
2. Average comfortable → add one row *or* one column, not both.
3. Then shuffle on, same size.
4. Then colour on, or Gorbov.

## Reading times

When times are pasted, report best and average, then:

- **5×5 only**, use bands: under 20 excellent, 21–25 good, 26–35 ok, over 35 slow.
- **6×4**, no bands — compare against the last set only.

Then give **one** form cue, and tomorrow's exact toggles and number of grids.
One cue, not a list.

## Commands

| Command | Meaning |
|---|---|
| `plan` | Today's taps and toggles, in four lines |
| `custom` | Assume 6×4, numeric, shuffle off, eyes on, colour off |
| `times 32 28 30` | Log seconds |
| `shuffle` / `color` / `5x5` / `gorbov` / `tired` | Switch the day's drill |
| `go` | Plan, now |

If a screenshot of the custom settings arrives, read the toggles, say what to
change before starting, then how many rounds.
